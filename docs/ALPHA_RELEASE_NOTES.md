# Commander 0.1.0 alpha 1

Commander is a fast, keyboard-first command bar and notification hub for Android. This first public alpha is intended for people who enjoy hardware keyboards, shortcuts, and direct access to common phone actions.

## Included in this alpha

- Search installed apps and launcher shortcuts.
- Add Todoist tasks with recognised dates and times.
- Search files and folders through Android storage.
- Start timers, calculate expressions, and convert units.
- Search contacts for calls and supported messaging flows.
- Configure aliases for common apps and search providers.
- Run selected Tasker tasks.
- Ask Gemini inside the command overlay or hand a query to ChatGPT.
- Read, filter, open, dismiss, and reply to supported notifications in Commander Hub.
- Customise the accent, glow, blur, result animation, and interface sounds.
- Export and import Commander settings between installations.

## Device testing

Most testing has been completed on the Unihertz Titan 2 and Zinwa Q25. Commander should also work on conventional Android phones and other keyboard devices, but keyboard handling, blur, background launches, and manufacturer restrictions vary. Device reports are welcome.

## Tested integrations

This release has been tested primarily with Todoist, Google Calendar, the default Clock app, Pastiera Enhanced, Solid Explorer, Gemini, ChatGPT, WhatsApp, and Facebook Messenger. Other compatible apps may work but have not received the same level of testing.

## Important limitations

- This is alpha software. Features may change and bugs are expected.
- Home-screen typing depends on Accessibility, the active launcher, and device keyboard behaviour.
- Commander Home is experimental and hidden in this release.
- WhatsApp and Messenger features depend on shortcuts, app intents, or live notifications with reply actions.
- Notification replies are only available when the originating app exposes Android direct reply.
- Blur appearance varies across Android versions and firmware.
- Gemini and Todoist credentials are not included in exported settings backups.

Please report issues with your phone model, Android version, keyboard, launcher, and clear reproduction steps.
