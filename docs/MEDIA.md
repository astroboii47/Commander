# Release media checklist

The alpha does not need a long promotional video. A few honest, focused captures will explain Commander better than a feature montage.

## Required before announcing broadly

### Hero clip: 10 to 15 seconds

1. Start in another Android app.
2. Open Commander Bar from a hardware key or gesture.
3. Type part of an app name.
4. Use an arrow key and Enter to launch it.

This should be the first media item in the README.

### Command clip: 8 to 12 seconds

Show one complete workflow, preferably Todoist or a timer:

1. Open Commander Bar.
2. Type the trigger and natural-language command.
3. Show recognised text and the selected result.
4. Press Enter.
5. Hold long enough to show the glow and success message.

### Hub clip: 10 to 15 seconds

Use test notifications with fictional names and content. Show keyboard navigation, category switching, opening a conversation, and a successful inline reply.

## Still images

Capture at least:

- Commander Bar over a visually recognisable app;
- app search with several results;
- a command with recognised natural-language tokens;
- Commander Hub with fictional notifications;
- Commander Settings showing the main appearance and keyboard options.

An optional photo of Commander running on a Titan 2 or Q25 is useful because it immediately communicates the keyboard-first purpose.

## Capture guidance

- Use a dedicated test contact and synthetic notifications.
- Hide email addresses, phone numbers, API keys, real tasks, calendars, and notification previews.
- Turn off unrelated status-bar notifications.
- Use the default accent and sound profile unless demonstrating customisation.
- Record at native resolution and keep an untouched master.
- Export README clips as a compact animated WebP or GIF, ideally below 10 MB.
- Attach an MP4 to the GitHub release for higher quality.
- Avoid music, narration, transitions, fake typing, or speed ramps in the first alpha demo.

## Suggested README layout

1. Hero clip
2. One-sentence description
3. Keyboard-first positioning and tested devices
4. Feature summary
5. Bar and Hub stills
6. Setup link
7. Limitations and privacy
8. Support link
